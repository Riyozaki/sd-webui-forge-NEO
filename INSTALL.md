# Установка ArbuzDiffusion

> **Коротко:** дважды кликни `install.bat` и жми Enter, пока не увидишь «Готово».
> То же самое, но в три строчки, лежит рядом в файле `КАК ЗАПУСТИТЬ.txt`.
> Если что-то не идёт — дважды кликни `doctor.bat`, он сам расскажет, что недоступно.

Установка в один клик. Python и git на компьютере **не нужны** — установщик приносит их с собой
внутрь папки.

## Что нужно

| | |
|---|---|
| Видеокарта | NVIDIA, от 6 ГБ VRAM (на 8 ГБ всё работает, на 4 ГБ — в режиме lowvram) |
| Система | Windows 10 (1809) или новее |
| Место на диске | 15 ГБ свободных (около 8–10 ГБ уходит под окружение с torch) |
| Интернет | нужен один раз, примерно на 3 ГБ |
| Python | не нужен, установщик поставит portable Python 3.11 внутрь папки |
| git | не нужен, без него просто не будет автообновления расширений |

## Установка

1. Скачай **`install.bat`** и запусти его. Если рядом нет остальных файлов форка, он сам
   докачает репозиторий (~45 МБ) в ту же папку — можно скачивать один этот файл.
   Хочешь целиком — `Code` → `Download ZIP` или `git clone`, это тоже работает.
2. Запускай из той папки, где форк и останется, — перенести потом можно, но проще сразу
   выбрать диск (и не из «Загрузок»: туда он распакует всё дерево).
3. Жми Enter, пока не увидишь «Готово».

Дальше запускается **`run.bat`**. Всё.

## Что делает установщик

```
[1/6] Python          -- portable Python 3.11 в installer_files\python (если своего ещё нет)
[2/6] Окружение       -- venv в installer_files\env
[3/6] pip             -- обновление pip и wheel
[4/6] torch           -- torch и torchvision под CUDA, с проверкой доступности источника
[5/6] Остальное       -- launch.py --exit: clip, open_clip, gradio, requirements.txt, расширения
[6/6] Настройки       -- webui.settings.bat, чтобы следующие запуски были такими же простыми
```

Шаг 5 установщик не делает сам: он запускает `launch.py --exit`, и проект ставит свои зависимости
своим проверенным способом. Так список пакетов никогда не расходится с `requirements.txt`.

Повторный запуск `install.bat` ничего не скачивает: уже установленное пропускается.

## Три варианта установки

Если на компьютере уже стоит torch, установщик это заметит и предложит выбор:

1. **Всё своё** (по умолчанию) — скачивается portable Python 3.11 и torch, всё живёт в папке форка
   и не зависит от того, что у тебя уже установлено. Медленнее, но предсказуемее.
2. **Использовать существующий torch** — venv создаётся с `--system-site-packages`, видит твой
   уже установленный torch и не скачивает его. Экономит около 3 ГБ и минут двадцать.
3. **Офлайн** — ставит из колёс, лежащих в `installer_files\wheels`. Сеть не нужна вообще.

## Куда что ложится

Всё, без исключения, внутри папки с форком:

| Путь | Что там |
|---|---|
| `installer_files\python` | portable Python 3.11, скачанный установщиком |
| `installer_files\env` | виртуальное окружение со всеми пакетами |
| `installer_files\cache` | кэши pip, HuggingFace, torch |
| `installer_files\tmp` | временные файлы (в том числе распаковка колёс и кэш torch.compile) |
| `installer_files\wheels` | сюда класть колёса для офлайн-установки |
| `models\`, `outputs\` | модели и результаты — как обычно |
| `webui.settings.bat` | настройки запуска, генерируются установщиком |

Ничего на диск `C:` не пишется: `webui.settings.bat` перенаправляет `PIP_CACHE_DIR`, `HF_HOME`,
`TORCH_HOME`, `XDG_CACHE_HOME`, `TEMP`, `TMP` и `GRADIO_TEMP_DIR` внутрь папки. Кэш torch.compile
и triton тоже попадает внутрь, потому что они сидят в `TEMP`.

Всё это (кроме `models` и `outputs`) можно удалить — `install.bat` восстановит окружение с нуля.

## Запуск

- **`run.bat`** — запуск. Браузер откроется сам (`--autolaunch` в `webui.settings.bat`).
  После установки на рабочем столе появляется ярлык **ArbuzDiffusion** — это тот же `run.bat`,
  можно пользоваться им или удалить, если мешает.
- **`doctor.bat`** — проверка сети одним кликом: что доступно, качает ли pip, что делать.
- **`console.bat`** — консоль с активированным окружением, если нужно что-то поправить руками:
  `pip list`, `python launch.py --update-all-extensions`, `git pull`.
- **`install.bat`** — повторный запуск: дособерёт, чего не хватает.

`webui.settings.bat` — обычный батник, его можно редактировать. Свои флаги запуска пиши туда
в `COMMANDLINE_ARGS`, например `set COMMANDLINE_ARGS=--autolaunch --medvram`.

## Если что-то пошло не так

**Непонятно, почему установка не идёт.** Запусти `install.bat --doctor` — он за 10–20 секунд
покажет, какие хосты доступны, может ли pip реально скачать пакет, и что с этим делать. Вывод
имеет смысл приложить к issue.

В первой строке установщик печатает свой номер сборки, например `ArbuzDiffusion [rev 5]`.
Если номер старый — ты запускаешь устаревшую копию файлов: скачай `install.bat` и
`scripts\arbuz_install.py` заново (или весь ZIP).

**Зависло на `Installing torch and torchvision`.**
Значит, `download.pytorch.org` недоступен. Перед установкой проверяется его доступность, и если
хост не отвечает, об этом пишется заранее. Что делать:

- положить колёса `torch-2.8.0+cu128-*.whl` и `torchvision-0.23.0+cu128-*.whl` в
  `installer_files\wheels` и запустить `install.bat` снова (вариант 3, сеть не нужна);
- или указать зеркало: `set TORCH_INDEX_URL=<зеркало>` и запустить `install.bat`;
- или выбрать вариант 2, если torch уже стоит.

**`torch не видит CUDA`.** Обнови драйвер NVIDIA. Проверка: в `console.bat` выполни
`python -c "import torch; print(torch.cuda.is_available())"`.

**Мало места.** Установщик предупредит, если свободно меньше 15 ГБ, и остановится, если меньше 6 ГБ.

**git не найден.** Не страшно: установка пройдёт, но расширения не будут обновляться автоматически.
Если нужен git — поставь [git-scm](https://git-scm.com/download/win) и запусти `install.bat` снова.

**Установщик распаковал всё в «Загрузки».** Он распаковывает репозиторий туда, откуда запущен.
Перенеси получившуюся папку куда нужно, а потом запусти `install.bat` уже на новом месте —
он пересоздаст окружение под новый путь.

**Хочу перенести папку на другой диск.** Проще всего скопировать её целиком: окружение привязано
к путям, но установщик это переживёт — при первом запуске на новом месте выполни `install.bat`,
он пересоздаст venv. Модели и результаты копируются как есть.

## Установка вручную

Если хочешь использовать свой Python 3.11:

```bat
python -m venv installer_files\env
installer_files\env\Scripts\python.exe -m pip install torch==2.8.0+cu128 torchvision==0.23.0+cu128 --extra-index-url https://download.pytorch.org/whl/cu128
installer_files\env\Scripts\python.exe launch.py --exit
```

и запиши в `webui.settings.bat` строку `set "VENV_DIR=%~dp0installer_files\env"`.

## Флаги установщика

`install.bat` передаёт аргументы в `scripts\arbuz_install.py`:

| Флаг | Что делает |
|---|---|
| `--yes` | не задавать вопросов, везде вариант по умолчанию |
| `--lang ru` / `--lang en` / `--lang auto` | язык сообщений (по умолчанию по кодировке консоли) |
| `--reuse-torch` | сразу вариант 2: venv поверх существующего torch |
| `--offline` | сразу вариант 3: только из `installer_files\wheels` |
| `--index-url URL` | свой индекс колёс torch вместо `download.pytorch.org/whl/cu128` |
| `--no-launch` | не предлагать запустить UI сразу после установки |
| `--doctor` | проверить сеть и выйти: что доступно, работает ли pip, что делать |

`doctor.bat` — то же самое, но без командной строки (флаги двойным кликом не передать).

Переменные окружения: `ARBUZ_PYTHON_URL` (откуда качать portable Python), `TORCH_INDEX_URL`.
